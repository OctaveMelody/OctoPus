# 章鱼简谱快速上手

**OctoPus: Octave + Jianpu for editing numbered-notation scores.**
**章鱼简谱：玩转八度，轻松制谱。**

章鱼简谱是一款**简谱**（数字记谱法）桌面编辑器。你用 **JPS**（Jianpu Script，简谱脚本）
编写乐谱，输入时即可看到**实时 SVG 预览**，可对照原稿图片或 PDF，并把成品导出为 SVG、PDF、
PNG 或 JPEG。编辑、渲染和转录全部在本地运行，无需联网。

本指南以经典歌曲**送别**为贯穿示例，带你从全新安装一步步走到导出成品，大约只需十分钟。

> 截图基于 Windows 桌面版界面。不同系统的菜单名称和可用字体可能略有差异。

## 1. 下载与安装

请从[章鱼简谱 GitHub 官方发布页](https://github.com/OctaveMelody/OctoPus/releases)直接下载最新版，
并在发布页面的资源列表中选择适用于当前操作系统的安装包。安装包
已含示例乐谱、快速上手指南和离线用户手册，安装后无需联网。

### Windows

- **安装包（推荐）：** 双击 `OctoPus_<版本>_x64_win64_setup.exe`，按向导操作。Windows 需要
  **WebView2**（多数机器已自带）。
- **便携版：** 解压 `OctoPus_<版本>_x64_win64_portable.zip` 到任意目录，运行
  `octopus.exe`。请保持整个文件夹完整——引擎和示例都在其中。



### macOS 26 或更高版本（Apple Silicon）

1. 打开 Apple Silicon 版 `OctoPus_<版本>_arm64_macos.dmg`，把**章鱼简谱**拖进「应用程序」文件夹。
2. 该版本尚未使用 Apple Developer ID 签名或公证。Gatekeeper 可能会阻止启动，并显示「应用已损坏」
   的警告。将应用复制到「应用程序」后，打开「终端」并运行：

   ```bash
   sudo xattr -cr /Applications/OctoPus.app
   ```

   该命令会递归清除应用包的扩展属性，其中包括导致 Gatekeeper 拦截启动的隔离标记。请仅对直接从
   GitHub 官方发布页下载的应用运行此命令。
3. 从「应用程序」启动**章鱼简谱**。

> macOS 桌面版使用你系统里已安装的 Apple 字体（PingFang SC、Songti SC 等）。如有缺字，请查看
> 「帮助 → 字体状态」。

### Linux

- **AppImage（推荐）：** 下载 `OctoPus_<版本>_x64_linux.AppImage`，给它可执行权限后运行：

  ```bash
  chmod +x OctoPus_*_x64_linux.AppImage
  ./OctoPus_*_x64_linux.AppImage
  ```

### 从源码运行（开发者）

请参阅 [ENVIRONMENT.md](../ENVIRONMENT.md) 中的环境和运行说明。

## 3. 你的第一张乐谱：送别

我们手动搭建**送别**的开头，看看源码文本如何变成音乐。

### 第 1 步 —— 新建文档

点击 **新建**（或 `Ctrl/Cmd + N`），填写文件名和必填标题；也可填写副标题、词作者、曲作者、其他作者、
调性、拍号和速度。点击 **确定**，程序会生成含描述头的新乐谱。

![新建乐谱对话框，文件名和标题栏中已填写《送别》。](screenshots/new-zh.jpg)

### 第 2 步 —— 输入描述头

**描述头** 用来描述乐谱：版本、标题、作者、调性、拍号、速度。每个字段都是「大写字母 + 冒号 +
空格 + 值」。将 **JPS 源码** 面板中生成的内容替换为：

```jps
V: 1.0
B: 送  别
Z: 李叔同 　　词
D: D
P: 4/4
J: 富于表情地
```

| 字段 | 含义 | 本例 |
| --- | --- | --- |
| `V` | 脚本版本 | `1.0` |
| `B` | 标题（重复 `B` 加副标题） | `送  别` |
| `Z` | 作者/署名（重复 `Z` 加多行） | `李叔同 　　词` |
| `D` | 调性——大写字母 A–G，`#` 升、`$` 降 | `D` |
| `P` | 拍号 | `4/4` |
| `J` | 速度——数值（显示为 `♩=` 加数字）、文字，或数字后接文字；单独占一行，显示在左边距 | `富于表情地` |

> ⚠️ 请使用 **半角 ASCII 标点**：冒号 `:`、双引号 `"`、逗号 `,`、单引号 `'` 和斜线 `/`。
> 整行以 `#` 开头是注释；音符中的 `#` 表示升号。

### 第 3 步 —— 输入第一行音乐

音乐行以 `Q:` 开头。单个数字是**四分音符**；空格分隔音符；`|` 是小节线。加入《送别》的一行唱段：

```jps
Q: 5 (3/ 5/) 1'. 7/ | 6 1' 5 - | 5 (2/ 3/) 4. 7,/ | 1 - - - |
```

一边读，一边看预览渲染：

- `5` `6` `1'` … 是音级（`'` = 高一个八度；`,` = 低一个八度）。
- `3/` 是八分音符（`/` 把时值减半）；`4.` 是附点音符。
- `-` 延长音符（增时线）。`0` 是休止符；`8` 是隐藏/占位休止。
- 括号将音符组合在连音线下。


### 第 4 步 —— 点击音符，联动源码与预览

**在 SVG 预览里点击一个音符**，章鱼简谱会在源码中高亮对应的记号（标为绿色）。在源码里点击记号
也能跳回预览。这个双向联动是编辑的最快方式：在谱面上找到音符，再在文本里改准那个字符。


### 第 5 步 —— 添加歌词

歌词行以 `C:` 开头，属于其正上方那行 `Q:`。汉字一般一字对应一音；`@` 跳过不唱的音；标点不唱。

```jps
C: 晚风@拂柳笛声残，夕阳@山外山。
```


复制 `C:` 行再替换文字即可加第二段；再加更多 `Q:` 行扩展整首。想试完整曲，选择 **打开**，
从示例文件夹加载 **Farewell.jps** 即可。

### 第 6 步 —— 保存成果

用 **另存为**（`Ctrl/Cmd + Shift + S`）把可编辑的原稿存为 `.jps` 文件。如果保存纯文本乐谱时
程序提示保留页面设置，请按提示操作。动手尝试前先保存副本。

> ✅ **黄金法则：** 一次只改 **一个记号**，看一眼预览，用 `Ctrl/Cmd+Z` 撤销。
> 渲染成功不代表音乐内容正确，仍需对照原稿校对。

## 4. 转录《送别》

用同一首歌试试转录。[《送别》原稿图片](user-manual/assets/examples/farewell-transcription.png)
展示了整首单页乐谱。

1. 保存当前工作，然后重启章鱼简谱，回到干净的初始页面。如果出现恢复提示，
   仅在确认不再需要恢复的内容时才选择丢弃。
2. 在**应用设置**中选择**对照区在上、编辑器在下（T2）**。通过
   **导入 → JPG / PNG / PDF…** 打开《送别》图片，再选择**转录曲谱 → 转录新建**，用草稿替换当前乐谱。
3. 将 SVG 预览设为**适配宽度**。对照完整原稿检查生成的多行乐谱；展开**检查转录问题**，
   点击一项可在原稿中用橙色框标出对应区域。

转录草稿只是起点，保存前请对照原稿检查音符和歌词。

![T2 转录布局中的《送别》：左侧显示完整原稿，右侧的适配宽度预览显示多行乐谱，下方是源码编辑器。](screenshots/transcription-review-zh.jpg)

![同一份《送别》原稿，选中一项检查结果，标题和署名区域以橙色框标出。](screenshots/transcription-findings-zh.jpg)

## 5. 调整页面排版

**输出页设置** 控制乐谱的排版方式和绘制字体。从工具栏打开（**输出页设置**）。

![《送别》的输出页设置。](screenshots/page-settings-zh.jpg)

主要分组：

| 分组 | 控制项 |
| --- | --- |
| **纸张与边距** | A4 / A5 纸张；上/下/左/右边距及正文起始位置。 |
| **字体** | 标题和歌词字体；音符样式（常规、斜体、粗体）。 |
| **字号** | 标题、副标题、歌词字号。 |
| **间距** | 曲到词、词到词、词到曲及声部间距。 |
| **其他** | 连音线样式：自动、圆弧或平顶。 |

按钮：

- **应用** — 立即更新预览，保持对话框打开。
- **确定** — 应用并关闭。
- **取消** — 放弃*尚未应用*的修改（已应用的不受影响）。

> 📏 字号和边距用的是**渲染器单位**，不是毫米。字体角色（黑体、宋体、楷体、仿宋）为每个文本角色
> 选择字族；在 Windows/macOS 上，章鱼简谱使用对应的已安装系统字体。**应用设置后请保存乐谱**
> 才能保留这些设置。

## 6. 导出最终成品页

预览满意后，点击 **导出**。选择 SVG 或 PDF，也可以在菜单中选择图片格式和分辨率：

![《送别》已打开时的导出菜单。](screenshots/export-zh.jpg)


| 菜单选项 | 用途 |
| --- | --- |
| **SVG…** | 矢量输出，缩放不会出现像素；查看器需要匹配字体。 |
| **PDF…** | 合并为一份多页文档，适合分享或打印。 |
| **JPG（96 DPI）… / JPG（300 DPI）…** | 有损压缩图片；打印请选择 300 DPI。 |
| **PNG（96 DPI）… / PNG（300 DPI）…** | 无损图片；打印请选择 300 DPI。 |

屏幕显示请选择 **96 DPI**，打印请选择 **300 DPI**。PNG 和 JPG 的分辨率直接显示在菜单选项中。

- PDF 生成**一份**合并文档；SVG/PNG/JPG 每页生成**一个文件**。
- **先保存 `.jps`** —— 它才是你可编辑的原稿；导出物是成品，不能再导回编辑。

## 7. JPS 语法速查表

JPS 是纯文本。一份乐谱由**描述头**开始，其后是音乐行（`Q:`），每行 `Q:` 后面跟它的歌词行
（`C:`）。空行和整行 `#` 注释用于提升可读性。

### 描述头

```jps
V: 1.0
B: Title
Z: Author
D: D
P: 4/4
J: 90
```

### 音符、音区与时值

| 符号 | 含义 |
| --- | --- |
| `1`–`7` | 音级 |
| `0` | 休止符（显示） |
| `8` | 隐藏休止（保留排版空间，不显示数字） |
| `1'` / `1''` | 高一个 / 两个八度 |
| `1,` / `1,,` | 低一个 / 两个八度 |
| `1 - -` | 音符加增时线（更长） |
| `1/` `1//` `1///` | 八分 / 十六分 / 三十二分音符 |
| `1.` `1..` | 单附点 / 双附点 |
| `4#` `7$` `3=` | 升 / 降 / 还原（写在数字之后） |

```jps
Q: 1 2 3 4 | 5. 6/ 7// 1'. - ||
```

### 小节线与反复

| 符号 | 含义 |
| --- | --- |
| `\|` | 普通小节线 |
| `\|\|` | 终止线（左细右粗） |
| `\|\|/` | 双细线 |
| `\|:` `\:|` `:|\|:` | 起始 / 结束 / 两侧反复 |
| `\|/` `\|*` | 隐藏小节线（不占位 / 保留宽度） |
| `\|\|&fine` `\|&dc.` `\|&ty` | 小节线上的 Fine / D.C. / Coda |

### 歌词

- 一个汉字 = 一个音符。标点不唱。
- `@` 跳过不唱的音。`~` 把两个字并为一个音。
- 英文音节用 `/` 分隔。
- 重复 `C:` 行加更多段落。

```jps
Q: 1 2 3 4 | 5 - 6 7 |
C: 春 风 @ 来 花~儿 开 了
C: 第二句也能写
```

### 进阶用法（稍后再试）

| 想要… | 写… | 示例 |
| --- | --- | --- |
| 倚音 | `1[23]`（前）/ `1[h23]`（后） | `1[2/3']` |
| 力度 | `&mp` `&ff` `&cresc` … | `1&mp` |
| 渐强/渐弱 | `<` 或 `>` … `!` | `1< 2 3 4!` |
| 连音线 / 多连音 | `(1 2 3)` / `(y1 2 3)` | `(1 2 3)` |
| 装饰记号 | `&yc` 延长、`&dy` 顿音、`&cy` 颤音 | `3&yc` |
| 跳房子括号 | `\|["1" … :|]` | `\|["1" 1 2 3 :|]` |
| 分页 | 单独一行 `[fenye]` | `[fenye]` |
| 多声部 | `Q1:`、`Q2:` 配 `C1:`、`C2:` | `Q1"Soprano": 1 2 \|` |
