# Quick start and user manual screenshots

The `*-en` and `*-zh` screenshots are captures of the installed Windows desktop app, version
1.0.0-RC3. The screenshots used in the quickstart guides show the same Farewell example in the
editing and transcription walkthroughs. Their English and Simplified Chinese pairs show the same
score, panels, and view settings. The import, settings, new-score, page-settings and export pairs
also show Farewell in the background.

The transcription screenshots were captured after restarting OctoPus and discarding any recovery
draft. They use the one-page Farewell reference image rendered from the Farewell JPS example, the
T2 layout, a full-page original, and a Fit Width SVG preview showing several music lines. The
findings pair shows the same selected issue and orange highlights in both languages.

The illustrated user manual reuses the localized pairs at the matching New score, workspace,
Import, transcription review, App Settings, Page Settings, and Export instructions. It retains the
separate score-rendering examples beside the JPS topics. These are local assets under
`docs/user-manual/assets/screenshots/`, so the manual does not depend on a repository checkout or
an image service when packaged.

The app's operating-system-specific font choices and some menu labels can differ on macOS and Linux.
