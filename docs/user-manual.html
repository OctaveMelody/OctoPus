Getting started

OctoPus edits Jianpu numbered music notation as JPS source and shows a live SVG score. Open the app, choose New, enter a title and select OK, or use Open for an existing .jps file. Samples Library opens bundled examples.

Use the Language selector to switch the app between English and Chinese. This manual has its own language tabs and works offline.

Open, save and close

Save writes the current document; Save As chooses another location. A new score needs a file location on its first save. The filename and Unsaved indicator appear beside Format source. Close closes the score; Exit closes the app. If there are unsaved changes, choose Save, Discard or Cancel in the prompt.

Reference images and PDFs are managed separately from JPS source; keep your originals. After an interrupted session, a recovery prompt can restore the working document and managed references.

Edit JPS source

Use Undo, Redo, Cut, Copy, Paste, Find and Replace. On narrow panes these actions are under Edit; Select All is available there too. Clipboard access depends on the operating system. Format source adjusts source formatting; it does not correct musical content. The filename may shorten or hide in very narrow panes.

A small score can use the following fields:

B: Practice
D: C
P: 4/4
Q: 1 2 3 4 | 5 6 7 1 |
C: 春 风 吹 来 花 儿 开 了

B is the title, D the key, P the time signature, Q a music row and C a lyric row. Digits 1–7 represent notes; 0 represents a rest and | a bar line. For detailed notation, start from a similar bundled example.

SVG preview and matching source

The preview updates while you edit. Moving or clicking the JPS cursor highlights its score position and brings that row toward the preview’s vertical center. Clicking a note or lyric in the preview selects its source text without moving the preview automatically.

Use −/+ for zoom, Fit page to see the whole page, and Fit width for readable width. Page arrows move between pages; Refresh renders again. When space is limited, View contains Fit page, Fit width, Prev Page and Next Page. Extremely narrow panes also provide zoom actions in View.

Warnings beneath the preview can be clicked to jump to their source location. A stale preview may still be visible while rendering; wait for the rendered status before exporting or reviewing a change.

Original image/PDF and transcription

Choose Import PNG/JPG/PDF…, or drop one PNG, JPG/JPEG or PDF into the Original Image/PDF panel. Native file dropping is supported in the desktop app. Import accepts one source file at a time; a PDF can contain several pages. If a reference is already open, confirm replacement or cancel. Unsupported, damaged or oversized files report an error.

Drag the reference to pan; use zoom, Fit page, Fit width and Rotate view 90°. These actions are under View when the pane is narrow. PDFs also have page navigation. × hides the reference pane by returning to Normal mode; the reference remains managed.

Transcribe offers New and Append drafts. New creates a provisional score; Append adds recognized music to the current source. A PDF is transcribed as a document, not just the displayed page. Review detected issues and compare against the original before saving the result. Recognition can miss or confuse notes, octave dots, slurs, grace notes, endings, lyrics and annotations; the draft needs human review.

Modes, layouts and focus

Normal mode shows JPS source and SVG preview. Transcription mode also shows the original. Choose N1 for side-by-side, N2 for stacked panes, T1 for three columns or T2 for original/preview above the editor. Width/height sliders adjust the split.

Focus Original, Focus Editor or Focus Preview temporarily expands a pane. Exit Focus restores the layout. Control rows automatically switch between full buttons and compact menus as panes resize. F11 still toggles the window’s maximized state.

Page settings and fonts

Page Settings controls paper size, fonts, spacing and score layout. Apply or confirm settings to update the score; a prompt resolves pending setting edits before a file action. Note styles are Regular, Italic and Bold. New scores default to HeiTi-1.

Export and share

Export offers SVG, PDF, JPG (96 DPI) and JPG (300 DPI). Choose an output location and wait for completion. SVG remains editable as vector artwork, but external viewers need the named fonts. PDF embeds the fonts; JPG stores pixels. Choose PDF or JPG when recipients need a consistent appearance. LilyPond conversion is not currently available.

For a portable app, keep the entire portable directory together, including engine, examples and docs. The executable contains the packaged Python worker; it does not need a separate Python install. Linux still needs GTK/WebKit runtime libraries and Poppler for PDF transcription; Windows needs WebView2.

Help, updates and troubleshooting

Help → User Manual opens this bundled page in your default browser, using the app’s current language. Report Issues opens GitHub Issues; Submit Requests opens the requested Pull Requests page. About OctoPus includes the project home.

Check for Update compares the installed version with the latest stable GitHub release. It reports a newer release, an up-to-date version, an unrecognized version tag, unavailable release information or a network error. Use the Releases link to inspect downloads and release notes. Checking does not replace the installed program.

If the preview fails, inspect its error message and source diagnostics, then try Refresh. For import/transcription problems, verify the source is a supported readable file and that PDF tools are available. For browser-opening problems, check that your operating system has a default browser. When reporting a problem, include your OS, app version, steps and a small non-sensitive example.

开始使用

OctoPus 用 JPS 源码编辑简谱，并提供实时 SVG 乐谱预览。启动后点击新建，输入标题并点击确定；也可点击打开载入已有的 .jps 文件。示例库提供随程序附带的乐谱。

程序的语言选择器可以切换英文和中文。本手册有独立的语言标签页，无需联网即可阅读。

打开、保存与关闭

保存写入当前文档；另存为可选择其他位置。新乐谱首次保存时需要选择文件位置。文件名和未保存标记位于格式化源码按钮旁。关闭可关闭当前乐谱，退出则关闭程序。有未保存修改时，可选择保存、放弃或取消。

参考图片和 PDF 与 JPS 源码分开管理，请保留原始文件。会话意外中断后，恢复提示可恢复工作文档和已管理的参考资料。

编辑 JPS 源码

可使用撤销、重做、剪切、复制、粘贴、查找和替换。面板较窄时，这些操作收入编辑菜单，同时保留全选。剪贴板访问受操作系统限制。格式化源码调整源码排版，不会自动纠正音乐内容。面板很窄时，文件名会缩短或隐藏。

以下是一段简短的乐谱源码：

B: 练习曲
D: C
P: 4/4
Q: 1 2 3 4 | 5 6 7 1 |
C: 春 风 吹 来 花 儿 开 了

B 表示标题，D 表示调号，P 表示拍号，Q 表示乐谱行，C 表示歌词行。1–7 表示音符，0 表示休止符，| 表示小节线。复杂记谱可从相近的附带示例开始修改。

SVG 预览与源码对应

编辑时预览会自动更新。移动或点击 JPS 光标会突出显示对应位置，并将该行移向预览的垂直中心。点击预览中的音符或歌词会选中对应源码，不会自动移动预览。

−/+ 用于缩放；适合页面显示完整页面；适合宽度按面板宽度显示。翻页箭头切换页面，刷新可重新渲染。空间不足时，视图菜单包含适合页面、适合宽度、上一页和下一页。面板特别窄时，缩放操作也收入视图菜单。

点击预览下方的诊断提示可跳转到相关源码。渲染期间可能仍显示旧预览；导出或检查修改前，请等待渲染完成状态。

原始图片/PDF 与转录

点击导入 PNG/JPG/PDF…，或将一个 PNG、JPG/JPEG、PDF 文件拖入原始图片/PDF 面板。文件拖放用于桌面程序。每次导入一个源文件；一个 PDF 可以包含多页。已有参考文件时，需要确认替换或取消。格式不支持、文件损坏或超出限制时会显示错误。

拖动参考页面可平移，使用缩放、适合页面、适合宽度和旋转视图 90° 调整显示。面板较窄时，这些操作收入视图菜单。PDF 还支持翻页。× 返回普通模式并隐藏参考面板，但已管理的参考文件会保留。

转录可新建草稿或追加草稿。新建创建临时乐谱；追加将识别的音乐内容加入当前源码。PDF 按整个文档转录，而不只是当前显示页。请检查识别问题，并对照原稿后再保存。识别可能遗漏或混淆音符、八度点、连线、倚音、结尾标记、歌词和注释，草稿需要人工校对。

模式、布局与聚焦

普通模式显示 JPS 源码和 SVG 预览，转录模式还显示原稿。N1 为左右布局，N2 为上下布局，T1 为三列布局，T2 为原稿/预览在上、编辑器在下。宽度和高度滑块调整面板比例。

聚焦原稿、聚焦编辑器或聚焦预览可临时扩大对应面板；退出聚焦恢复原布局。面板宽度变化时，工具栏会自动在完整按钮和紧凑菜单之间切换。F11 仍可切换窗口最大化状态。

页面设置与字体

页面设置用于调整纸张、字体、间距和乐谱布局。应用或确定设置后乐谱会更新；文件操作前若有未应用的设置，会出现处理提示。音符样式为常规、斜体和粗体。新文档默认使用 HeiTi-1。

导出与分享

导出提供 SVG、PDF、JPG（96 DPI）和 JPG（300 DPI）。选择保存位置并等待完成。SVG 是可编辑矢量图，但外部查看器需要安装所指定的字体。PDF 嵌入字体，JPG 保存像素；需要一致外观时可选择 PDF 或 JPG。目前不支持 LilyPond 转换。

便携版需要保留整个目录，包括 engine、examples 和 docs。程序附带 Python 工作进程，不需要另装 Python。Linux 仍需要 GTK/WebKit 运行库及用于 PDF 转录的 Poppler；Windows 需要 WebView2。

帮助、更新与排查

帮助 → 用户手册使用系统默认浏览器打开本手册，并采用程序当前语言。报告问题打开 GitHub Issues；提交请求按要求打开 Pull Requests 页面。关于 OctoPus中提供项目主页链接。

检查更新将已安装版本与最新的 GitHub 稳定发布版本比较。结果会说明发现新版本、已是最新、版本标签无法识别、发布信息不可用或网络错误。发布页面链接可用于查看下载和发布说明。检查更新不会替换已安装程序。

预览失败时，请检查错误提示和源码诊断，然后尝试刷新。导入或转录失败时，确认文件格式受支持且可读，并检查 PDF 工具是否可用。无法打开浏览器时，请检查系统默认浏览器设置。报告问题时，提供操作系统、程序版本、复现步骤和一个不含敏感信息的小示例。
